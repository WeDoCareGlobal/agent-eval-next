Agent Eval
Agent Evaluation & Observability Platform

Measure agent performance, observe tool usage, and continuously evaluate RAG, policy, and workflow outputs.

Apache 2.0 ORCID: 0009-0009-8515-2727 Version: v0.1.2 DOI: 10.5281/zenodo.23108384
Star on GitHub ↗ Quickstart → Live App ↗

The Problem

Agents run in production with no visibility into: How many tokens did this agent burn? Which tools failed and why? Is latency degrading? Are we getting the right answers? Most teams fly blind until something breaks.

Agent Eval answers

  • Per-agent latency, token usage, success rate, error classification
  • Full tool-call tracing (input/output/decision/approved-by)
  • Continuous benchmark scenarios for RAG, policy, workflow quality
  • Shared audit log format with AgentGuard for unified governance
  • Real-time WebSocket telemetry stream + dashboard

Features

Observability built for autonomous agent fleets.

Agent Metrics

Latency percentiles, token usage (prompt/completion/total), success rate, error taxonomy per agent.

Tool Observability

Trace every tool call: input, output, decision (allowed/denied/approval), duration, caller.

Continuous Eval

Run benchmark scenarios on schedule. Track RAG quality, policy compliance, workflow correctness over time.

Audit Integration

Shared log format with AgentGuard. Single source of truth for governance + observability.

Live Dashboard

Real-time WebSocket stream. Token cost graphs, latency distributions, tool-path sankey.

Multi-Provider

Supports 14+ LLM providers (OpenAI, Anthropic, NVIDIA, xAI, Mistral, local, etc.)

Quickstart

git clone https://github.com/we-do-care-global/agent-eval.git
cd agent-eval
pip install -e .
# Configure .env for providers
pytest --eval-scenarios scenarios/
# Or run server:
uvicorn agent_eval.server:app --reload
# Dashboard at http://localhost:8080
